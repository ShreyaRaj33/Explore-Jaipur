# 🌆 Explore Jaipur

## 📌 Description
Explore Jaipur is a simple web project built using HTML and CSS that showcases the beauty and culture of Jaipur. It highlights famous places, including palaces, food cafes, and local markets, giving users a quick virtual tour of the city.

## 🚀 Features
- 🏰 Famous palaces and historical places
- 🍴 Popular food cafes and eateries
- 🛍️ Local markets and shopping spots
- 🎨 Clean and simple user interface

## 🛠️ Tech Stack
- HTML
- CSS

## ▶️ How to Run
1. Open the project folder
2. Double-click on the `index.html` file  
   OR  
3. Open it in any web browser
